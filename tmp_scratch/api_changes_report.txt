===============================================================================
1. GuiGraphics - REMOVED
===============================================================================
Status: REMOVED entirely. No GuiGraphics class exists.
Replacement: net.minecraft.client.gui.GuiGraphicsExtractor
  - Package: net.minecraft.client.gui
  - Class: public class GuiGraphicsExtractor implements GuiGraphicsExtractorExtension
  - Constructor: GuiGraphicsExtractor(Minecraft minecraft, GuiRenderState guiRenderState, int mouseX, int mouseY)
  - Also: GuiGraphicsExtractor(Minecraft minecraft, Matrix3x2fStack pose, GuiRenderState guiRenderState, int mouseX, int mouseY)
  - Key methods: fill(), horizontalLine(), verticalLine(), enableScissor(), disableScissor()
  - pose() returns Matrix3x2fStack (not PoseStack!)
  - guiWidth(), guiHeight() for dimensions
  - NO renderItem, blit, drawString methods on this class (rendering has changed to state-based extraction)

NOTE: Gui.java exists but is completely different:
  - Package: net.minecraft.client.gui
  - Class: public class Gui (NOT abstract, no longer has GuiGraphics parameter in render methods)
  - Has field: public final Hud hud
  - GuiRenderState-based rendering

20. Camera access via GameRenderer
===============================================================================
net.minecraft.client.renderer.GameRenderer:
  - Package: net.minecraft.client.renderer
  - Field: private final Camera mainCamera (PRIVATE!)

Access pattern:
  - gameRenderer.mainCamera is PRIVATE, not directly accessible
  - Camera is set up via: this.mainCamera.setEntity(player) and this.mainCamera.tick()
  - Camera update: this.mainCamera.update(deltaTracker)
  - Camera class: net.minecraft.client.Camera

The render state extraction pattern:
  this.mainCamera.extractRenderState(cameraState, cameraEntityPartialTicks);

For entity renderers, camera is passed as CameraRenderState parameter:
  void submit(State state, PoseStack poseStack, SubmitNodeCollector collector, CameraRenderState camera)

To get camera position in render code:
  - Use camera parameter (CameraRenderState) passed to submit/extract methods
  - CameraRenderState has orientation field (Quaternionf)

SUMMARY OF CRITICAL CHANGES
===============================================================================
1. GuiGraphics -> GuiGraphicsExtractor (different API, Matrix3x2fStack based)
2. MultiBufferSource -> SubmitNodeCollector (everywhere)
3. RenderType moved to net.minecraft.client.renderer.rendertype
4. RenderStateShard REMOVED, replaced by RenderSetup/RenderPipeline
5. Entity.hurt() is final, use hurtServer() for override
6. Entity.moveTo() REMOVED, use setPos()
7. Mob.doHurtTarget now takes ServerLevel parameter
8. BlockEntity loadAdditional/saveAdditional use ValueInput/ValueOutput (not CompoundTag)
9. ArmorItem REMOVED, replaced by Equippable data component
10. FastColor REMOVED, replaced by ARGB utility
11. HierarchicalModel REMOVED
12. TextureSheetParticle REMOVED, use SingleQuadParticle
13. VariantHolder REMOVED
14. DripstoneThickness RENAMED to SpeleothemThickness
15. ItemProperties REMOVED, replaced by data-driven property system
16. Camera in GameRenderer is private, use CameraRenderState parameter
